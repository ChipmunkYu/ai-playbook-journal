# 竹鱼团扇到雪兔团扇 prompt 对话记录

日期：2026-05-14

主题：中国传统团扇 / 写意竹子 / 水波墨鲤 / 冬日竹兔

说明：这是一份较长的迭代会话记录，从竹子、水波、鲤鱼的团扇画面调整，延伸到冬日竹子与兔子的团扇图像，并包含一次完整兔子 prompt 总结。

---

### 1. 用户

```text
画面形式为中国传统团扇扇面构图，整体偏圆形团扇。
风格为中国古风写意水墨画，参考传统国画与文人画，而非现代插画或写实绘画。
不要印章、题诗、书法文字。
不模仿旧纸破损、颜料剥落、裂痕做旧等效果。
整体气氛安静、清冷、留白适中，有东方水墨中的空灵感。

色彩：
整体采用传统中国水墨画配色，以温润米赭色宣纸为底，搭配浓淡不同的灰黑墨色。色彩低饱和、柔和克制，以淡墨、灰墨、焦墨形成层次，不使用鲜艳颜色，营造古雅、安静、空灵的东方文人画气氛。配色接近宋元小品与文人册页中的淡设色水墨风格。

竹子部分：
竹子是主要主体。
竹竿采用传统国画中的画法：
竹节明确但简练；
用笔偏书法式笔触；
不要真实体积感与强烈光影；
不要现代素描式写实。
竹竿需要有浓淡变化：
有深墨主竹；
有淡墨陪衬竹；
形成层次错落。
竹竿之间轻微交叉，
不要大量平行。
左下竹竿起始位置不要全部集中于同一点。
不显示竹根和地面。
竹子整体偏左布局。
左侧竹群需要有主次关系：
主竹较粗较浓；
辅竹较细较淡。

竹叶部分：
竹叶不能机械重复。
每一簇竹叶都应略有差异：
数量不同
长短不同；
疏密不同；
朝向不同；
墨色不同。
竹叶分布要有疏密错落：
有些区域密；
有些区域稀；
不平均铺满。
有竹叶延伸到右上区域，用于平衡留白。
画面顶部需要部分竹叶填补空白，但不能完全填满。

水与鱼部分：
右下保留水面与水波。
水波轻淡、克制、偏写意。
有两条墨色鲤鱼。
鲤鱼保留优雅流线型身体结构。
减少鱼鳞与细节描绘：
偏水墨晕染；
不工笔写实。
鱼、水波整体保持安静感，不抢竹子主体。
鲤鱼身体呈自然流畅的弧线弯曲；
不是僵直游动，而是像在水中缓慢转身；
身体形成柔和的 S 型或半环形曲线；
鱼头与尾巴方向不同，形成回旋感；
尾部轻轻甩开，有水中摆尾的韵律；
动作安静，不是跃起或剧烈游动；
像在缓慢盘旋、绕水而行；
强调“游势”而非解剖结构；
整体有书法线条般的流动感。

皴擦与背景：
背景允许少量淡墨皴擦痕迹。
皴擦主要用于：
平衡空白；
营造烟气、水气、空间感。
右侧皴擦不能太重。
右上竹叶附近可有少量淡皴擦辅助层次。
留白很多，但不能出现“大块完全空”的区域。

整体构图倾向：
左侧竹群 + 右侧水鱼的对角平衡结构。
强调“不满”“不挤”“不均匀”的自然感。
画面应像传统文人小品：
克制；
松弛；
有呼吸感；
非装饰图案式重复。
```

### 42. 助手

```text
中国传统团扇扇面构图，整体为圆形团扇画面。
风格参考中国古代文人画、写意水墨、小品册页，而非现代插画、厚涂或写实绘画。
整体气氛安静、空灵、含蓄，有冬日雪后竹林中的清冷感。
不要题字、印章、书法、做旧裂纹、破损纸张效果。

色彩采用传统中国水墨淡设色体系：
以温润米赭色宣纸为底色；
使用灰墨、淡墨、焦墨形成层次；
颜色低饱和、柔和克制；
强调毛笔蘸墨后的晕染感与笔锋变化；
有传统国画中“墨色渗入宣纸”的质感；
不要数码喷枪感与现代平滑渐变。

构图：
左侧为冬日竹子；
右下为一只兔子；
整体形成“左竹右兔”的留白平衡结构；
画面留白较多，但不出现完全空白的大块区域；
背景可有少量淡墨水气、雪气皴染。

竹子部分：
竹竿较细，不厚重；
采用中国古画中写意竹竿画法；
不要明显黑色勾线轮廓；
竹节简练自然；
竹竿有浓淡层次；
部分竹竿较淡作为陪衬；
竹竿轻微交叉，但角度不要太剧烈；
整体疏朗清秀。

竹叶部分：
竹叶采用写意毛笔笔触；
不要机械重复；
每一簇竹叶的数量、方向、形状、浓淡都不同；
有疏密变化；
部分区域较密，部分区域较空；
竹叶上覆盖少量积雪；
雪不是厚重堆积，而是轻轻覆在叶尖与竹节处；
墨叶与白雪形成对比。

兔子部分：
兔子不要写实；
采用中国水墨写意小动物画法；
轮廓柔和；
身体略带圆润感；
减少真实毛发细节；
强调墨色块面与毛笔晕染；
动作为轻轻甩头抖落头顶积雪；
不是剧烈动作；
雪花轻轻散开；
兔子姿态安静可爱，但带一点冬日灵气；
耳朵自然下垂或轻微摆动；
整体更像古画中的“意象兔”而非真实动物解剖。

地面与雪景：
地面仅用少量淡墨与留白表现积雪；
不画复杂环境；
可有几根枯草或淡墨草叶；
雪地边缘虚化；
整体保持空灵、克制。

画面整体要求：
强调中国传统水墨写意中的“气韵”；
有呼吸感；
不满、不挤、不均匀；
像宋元文人册页中的冬景小品；
以笔墨关系和留白营造意境，而不是靠细节堆砌。
```
